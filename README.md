# egypt_spatial_disparities
# 🎓 مبادرة عقول ذكية – ملخصات الدراسات

هذا المستودع يحتوي على ملخصات دراسات **معهد التخطيط القومي** ضمن مبادرة **عقول ذكية** لتدريب الشباب على مهارات الذكاء الاصطناعي والتنمية المستدامة.

---


## 🎯 الهدف
- تمكين الشباب من الوصول إلى ملخصات علمية مبسطة.
- دعم عملية التعلم الذاتي باستخدام أدوات الذكاء الاصطناعي.
- تعزيز الوعي بأهمية التخطيط القومي والتنمية المستدامة.

---

## 📂 محتويات المشروع
- `ملخص_التنمية_المستدامة.pdf` → ملخص حول مفاهيم التنمية المستدامة.
- `ملخص_التحول_الرقمي.pdf` → ملخص حول التحول الرقمي وأثره على التعليم.
- `ملخص_الذكاء_الاصطناعي.pdf` → مدخل إلى مهارات الذكاء الاصطناعي للشباب.
